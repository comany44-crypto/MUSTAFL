# Jannah Al-Harith Professional Website

موقع شركة كامل مع لوحة تحكم لإدارة المنتجات ورفع الصور.

## التشغيل محلياً
1. ثبّت Python 3.10 أو أحدث.
2. افتح Terminal داخل مجلد المشروع.
3. نفّذ: `python -m venv .venv`
4. فعّل البيئة ثم نفّذ: `pip install -r requirements.txt`
5. شغّل: `python app.py`
6. افتح: `http://127.0.0.1:5000`

## لوحة الإدارة
- الرابط: `http://127.0.0.1:5000/login`
- المستخدم الافتراضي: `admin`
- كلمة المرور الافتراضية: `ChangeMe123!`

**مهم جداً:** غيّر كلمة المرور وSECRET_KEY قبل رفع الموقع على استضافة عامة.

## الميزات
- موقع عربي/إنجليزي ووضع ليلي في الواجهة.
- لوحة إدارة محمية بتسجيل دخول.
- إضافة/تعديل/حذف المنتجات.
- نشر أو حفظ كمسودة.
- رفع صور بصيغ PNG/JPG/JPEG/WEBP.
- قاعدة بيانات SQLite تُنشأ تلقائياً.

للنشر الاحترافي يُنصح باستخدام متغير بيئة SECRET_KEY واستضافة تدعم Python/Flask مع تخزين دائم للملفات وقاعدة البيانات.
